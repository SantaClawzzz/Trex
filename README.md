# Google Chrome dinasour game
**Consists of:**<br>
* 1x Raspberry Pico (not original used) (can be any MCU)
* 1x ILI9341 (TFT screen 2.8" 340x240)
* 2x Buttons

## What

Currently only works with USB-C power, can be designed with integrated battery but MCU doesn't have any ways to charge it

Previously done on a ESP-WROOM devkit and uses PROGMEM, Raspberry can't use it, it was changed so it still works but highscore won't be saved
